Editors

Editor support lives in separate repositories of the kite-language organization, each with its own version (see versions.md).

editor repository / path how to use
VS Code vscode-kite install the .vsix (kite-language.kite-language-vscode)
Zed zed-kite (grammar from tree-sitter-kite) zed: install dev extension, or the registry once published
Neovim, Helix tree-sitter-kite tree-sitter grammar + queries/
Kate, KWrite, KDevelop kate-kite scripts/install.sh (copies kite.xml to ~/.local/share/org.kde.syntax-highlighting/syntax/)
Notepad++ notepadpp-kite run install.ps1 or import Kite.xml
GitHub linguist/ (this repo) material for a pull request to github-linguist/linguist

Local development of everything at once: scripts/dev-install.sh --help.
